# Maklyxa69 Prank Window

Шуточная программа для Windows x64. При запуске появляется окно с надписью «ваша устрайсто было з1хв1ч6но» и подписью `maklyxa69`.

Скачай `maklyxa69.exe` в разделе [Releases](https://github.com/qqew666/prank-window/releases). Картинку можно добавить кнопкой «Выбрать фото…» или сохранить рядом с программой под именем `photo.jpg`.

Чтобы закрыть окно, введи `123` и нажми Enter. Esc и крестик тоже работают.
